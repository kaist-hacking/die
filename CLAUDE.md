# Writing Style Guide

Write in this voice when drafting or editing prose. When asked to make a specific
edit, change only that — flag any other issues separately and ask before touching
them; do not fold unrequested changes into the same edit.

## Voice

- **Active voice; `we` or the system name is the subject.** "We observed that…",
  "\sys generates…". Not "it was observed that".
- **No first-person singular.** Always the collective "we".
- **Assert directly; hedge rarely and precisely.** Default to flat assertion.
  Sanctioned hedges: "To the best of our knowledge,", "suggests that".
- **Plain, precise verbs:** propose, devise, observe, identify, demonstrate,
  alleviate, tailor, overcome. No "utilize" for "use".

## Shape

- **Claim first (deductive).** First sentence of a paragraph states the point; the
  rest supports it.
- **Short, already-defined subjects;** put the new idea in the predicate.

## Transitions

Pivot sentences and paragraphs on explicit, front-loaded markers, each chosen to
match the actual relationship it signals:

- Contrast / problem: **However,** / **Unfortunately,** / **Despite …,** /
  **Unlike X, Y…**
- Addition: **Moreover,** / **Furthermore,** / **Additionally,**
- Emphasis: **More importantly,** / **It is worth noting that,** / **Thanks to …,**
- Framing: **Recently,**

The contribution paragraph opens with **"In this paper, we …"**.

## Problem framing

- **Juxtapose to expose the gap:** "A is fast but imprecise; B is precise but
  slow."
- **Praise prior work, then puncture it** with "However," / "Despite…".
- **Make causality explicit:** "…thereby allowing…", "…leading to X, Y, and Z".

## Grounding claims

- **Every quantitative claim carries a citation and a concrete number** — never
  "many" when a number exists.
- **Report results as "X out of Y"** (e.g., "42 out of 50 cases").
- **Follow each abstract claim with a concrete example** ("For example, …" or
  inline "e.g., …").

## Naming & glossing

- **Introduce a system or concept by apposition:** "we propose \sys, a tool for
  …", "a technique, called X, that …".
- **Gloss inline with parentheticals:** `i.e.` for a restatement, `e.g.` for
  examples — keep them short.
- **Em-dash for an emphatic appositive or consequence.**

## Stakes

- **Name the consequence concretely** — not "serious problems" but the specific
  outcome (e.g., "arbitrary code execution").
